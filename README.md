# 🧑🏻‍💻 Robson Rocha

**`Desenvolvedor Web | Backend & Frontend`**

Me chamo Robson Rocha Silva, tenho 22 anos e sou formado em Análise e Desenvolvimento de Sistemas pela Unopar. Atualmente, atuo como Desenvolvedor Web na DGTAX Company, desenvolvendo soluções para aplicações web, automação de processos, integração de APIs e manipulação de dados.

Tenho experiência principalmente com desenvolvimento em Python, criação de APIs, automação utilizando Playwright, Docker e bancos de dados PostgreSQL. Também desenvolvo interfaces utilizando Vue.js, TypeScript e Tailwind CSS. Estou sempre buscando aprender novas tecnologias e aplicar boas práticas para construir aplicações escaláveis, performáticas e de fácil manutenção.
